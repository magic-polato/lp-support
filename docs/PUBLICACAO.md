# Preparação da publicação

Nome: `lp-support`

Descrição sugerida: Central de suporte técnico para Windows em BAT e PowerShell, com diagnósticos, histórico por chamado e relatórios. Projeto de Leonardo Polato em validação.

Tópicos sugeridos: powershell, windows, technical-support, automation, diagnostics, itsm.

O pacote não contém logs reais, credenciais, capturas de clientes ou relatórios de produção. A licença está pendente de decisão do autor; não anunciar como software open source licenciado até essa definição.

## Primeira publicação

Publique os arquivos e diretórios da raiz do pacote, preservando a estrutura. O README será a página inicial do repositório. Antes de distribuir como versão estável, conclua o plano de validação em Windows. Se criar uma release antes disso, identifique-a como pré-lançamento em validação.

## Texto para LinkedIn

Estou desenvolvendo a LP Support, uma central de suporte técnico para Windows que reúne diagnósticos, manutenção e documentação de atendimentos.

O projeto nasceu de tarefas recorrentes da rotina de TI e evoluiu para 35 opções organizadas por categoria, com histórico por chamado, relatórios em HTML/TXT, verificação de privilégios e confirmação das alterações.

Minha proposta é aplicar a experiência em suporte e gestão de serviços a uma ferramenta prática, desenvolvida com apoio de inteligência artificial na implementação e revisão do código.

A versão 2.0 passou por testes de lógica e simulações. O próximo passo é validar os comandos em Windows de laboratório. Ainda não é uma versão homologada para produção.

Código e documentação: https://github.com/magic-polato/lp-support
